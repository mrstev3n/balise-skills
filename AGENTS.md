## Skill Market centre de contrôle

When this repository is attached to `Lab Skills & MCP`, read `docs/project/CONTROL_CENTER.md` before material work and report to `🗼 Skill Market — Centre de contrôle` (`01a00a7d-2e51-7881-9cf5-ad0789717ba2`). That child centre coordinates this repository only and reports upward to the parent `🗼 Lab Skills & MCP — Centre de contrôle` (`01a00a76-0e12-7bd0-8344-f8266282dc4b`).

Preserve existing marketplace changes, keep canonical skills, public editions, adapters and catalogue separate, and send the applicable centre a report at useful milestones and at mission end.

The marketplace remains a downstream publication surface: do not publish, push, create remotes, or change release state without explicit authorization and the repository’s own verification gates.
