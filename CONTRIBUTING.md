# Contributing

Contributions that improve the catalogue, documentation, validation, or existing skills are welcome.

## Requirements

1. Keep each canonical skill under `skills/<skill-id>/`.
2. Limit `SKILL.md` frontmatter to `name` and `description`.
3. Place detailed guidance in directly linked `references/` files.
4. Keep harness-specific metadata under `adapters/`.
5. Update catalogue and collection manifests when discovery metadata changes.
6. Submit only material you have the right to license under Apache-2.0.
7. Run `npm run validate` before opening a pull request.

Pull requests should explain the user-facing change and include the relevant validation evidence.
