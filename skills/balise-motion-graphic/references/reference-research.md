# Reference research

Use this reference for motion moodboards, source selection, contact sheets, and temporal analysis. Recheck live access, pricing, and downloadable-asset terms at task time.

## Focused protocol

1. Name the unanswered question: narrative, composition, typography, transition, material, camera, sound, loop, or asset treatment.
2. Choose only the source roles needed: direction, composition, craft, or asset.
3. Stop when one strong direction can be prototyped or the required prompt, asset, sequence, or mechanism has been found.
4. Capture opening state, transition, regime, exit, and resolution.
5. Extract 12–24 frames or denser samples around critical changes when temporal evidence helps.
6. Decide what to copy closely, reconstruct, adapt, combine, or generate.

Copying a prompt, sequence, transition, or public source can be the most efficient route. A faithful reprise is valid when requested. Otherwise adapt the material through project context, multi-source combination, or execution quality.

Do not require author records, consultation dates, exact URLs, provenance logs, or one reference per decision. Keep a link only when reopening the material helps production. Record licenses and attribution only for an external asset actually acquired and integrated.

## Useful outputs

- reference or contact board only when visual comparison helps;
- beat map for hooks, pauses, impacts, transitions, exits, and sound cues;
- Motion DNA: timing, forces, amplitude, density, depth, camera, typography, and sound;
- avoid list only for known failure modes relevant to the project.
